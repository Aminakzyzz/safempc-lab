# Report scaffold

This folder is a deliberately small LaTeX starting point for a future paper or technical report.

1. Replace the title and author fields in `main.tex`.
2. Add claims only with supporting references in `references.bib`.
3. Keep generated PDFs and LaTeX auxiliary files out of version control.
4. Compile locally with `latexmk -pdf main.tex` when a TeX distribution is available.

The scaffold is local only. It has not been committed or pushed in this repository.
