02 / scope

What the final artifact contains.

The work is deliberately staged so the project remains explainable and every advanced feature has a baseline.

Adaptive SafeMPC Lab

A differential-drive robot follows a reference path while its true actuator gain changes. The controller observes the mismatch, estimates it online, and updates the prediction model. Safety constraints are treated separately and evaluated honestly.

  • INPUT Reference path, state estimate, obstacle data
  • UNCERTAINTY Wheel slip, actuator drift, sensor noise, delay
  • OUTPUT Speed and turn-rate command plus evidence logs
  • MEASURES Error, effort, clearance, feasibility, solve time
