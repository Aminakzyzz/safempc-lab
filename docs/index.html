Robotics control portfolio

SafeMPC
Lab

A transparent, reproducible benchmark for safe differential-drive robot navigation.

Question

How do controller choice, constraints, and model mismatch affect tracking and safety?

Why it matters

It makes control-theory preparation visible through code, tests, experiments, and technical documentation.

Current build

● Implemented
  1. Differential-drive dynamics with Euler and RK4 integration
  2. Pure-pursuit baseline and discrete-time LQR tracker
  3. Input limits, obstacle safety monitor, deterministic tests
  4. Public repository, CI workflow, and Modal experiment scaffold

Next milestones

  1. Constrained QP MPC and fair controller comparison
  2. Monte-Carlo parameter sweeps on Modal
  3. Control-barrier-function safety layer
  4. ROS 2 simulation wrapper and latency report
